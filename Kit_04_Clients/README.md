# Kit 04 — العملاء ونظام الفولدرات

> هنا نظام فولدرات العملاء والتسمية والأكواد، وملف لكل عميل فيه ستايله وقراراته.
> ملفات العملاء نفسها مش في الريبو: `git` مش بيتتبّع أي ملف هنا غير الملف ده.
> مكان فولدر العملاء على الجهاز مكتوب في `THIS-PC.md`. تحت ده بكتبه `<Clients>`.

---

## 1. نظام الفولدرات

```
<Clients>\
  <اسم العميل>\
    Master Assets\                 ← لوجوهات وهوية العميل والريفرنسات
    <ملفات البلان docx / pdf / pptx>
    CLAUDE.md                      ← 3 سطور (قسم 2)
    ريل 1\ … ريل 10\
      assets - <CODE> R<N>\        ← البريف، الفويس، اللوجو، المزيكا، برومبتات التوليد
      footage - <CODE> R<N>\       ← كليبات الـ AI بأسماء L01 … L16 بترتيب الشوتس
      exports - <CODE> R<N>\       ← <CODE>_R<N>.mp4 + previews\
      <CODE>_R<N>.aep
      Beats-Plan-<CODE>-R<N>.md
      PROJECT_STATE.md             ← حالة الريل وآخر نسخة، عشان أي جلسة تكمّل
      scripts\                     ← build_<CODE>_R<N>.jsx + اللوجات
      R<N>_sfx\                    ← stems + cue sheet + سكريبت الميكس
```

- **قبل ما تكتب أي بلان أو أسيت أو إكسبورت لريل عميل**، افتح `<العميل>\ريل N` واستخدم فولدراته وكوده.
- **فولدر الجلسة مش بيقولك الشغل يتحط فين.** الشغل مكانه فولدر العميل.
- **اللوج بتاع أي سكريبت** يتكتب جنب السكريبت في `scripts\`، مش في فولدر مؤقت.

---

## 2. العملاء والأكواد

- **كل عميل ليه ملف هنا** باسم `<CODE> - <الاسم>.md`، وكود من 3 حروف إنجليزي كابيتال. اسأل المستخدم على الكود قبل ما تعمله.
- **أول ريل لأي عميل جديد** يتعمل له الملف: الريفرنس، الستايل، الكابشن، الإند كارد، القرارات، وفي آخره «قايمة فحص قبل التسليم» من قواعده الإجبارية بس.
- **ملف `CLAUDE.md` في فولدر العميل** 3 سطور: اسم العميل وكوده، وأمر «قبل أول رد اقرا ملف العميل كله» بمساره هنا، واكونت التوليد المسموح.
- **الريل اللي عليه الدور:** ادخل فولدر العميل وشوف آخر ريل ليه فيديو في `exports`، واللي بعده هو اللي عليه الدور. أكّد مع المستخدم الأول.
- **لو مش واضح الريل لأنهي عميل**، اسأل.
- **ملف العميل بيتحدّث في مراجعة آخر الجلسة** (`START-HERE.md` قسم 7)، وأي كلام فيه بقى قديم يتشال.
