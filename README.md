# ورك فلو مونتاج الريلز مع Claude Code

> نظام عمر لمونتاج وموشن جرافيك ريلز `9:16` بـ `Claude Code`: قواعد، وسكيلز لكل نوع ريل، وأدوات، وهوكات بتخلّي النظام يراجع نفسه آخر كل جلسة.
> النسخة دي بتتولّد لوحدها من نسخة عمر الخاصة بعد كل مراجعة. أسامي العملاء متبدّلة بأكواد (`CLA`، `CLB`…) ومفيش فيها مفاتيح.

---

## التسطيب (مرة واحدة)

المطلوب على الجهاز: ويندوز، و`Claude Code`، و`git`، و`Python 3`. باقي البرامج (After Effects، `ffmpeg`، الخطوط…) في `NEW-PC-SETUP.md`، و`Claude` هيقولك الناقص منها.

```bash
git clone https://github.com/omarsayedahmed3322-spec/claude-video-workflow Claude-Workflow
```

```bash
python Claude-Workflow/install.py --dry-run
```

```bash
python Claude-Workflow/install.py
```

- الأمر التاني بيعرض كل خطوة من غير ما يكتب حاجة. شوفه الأول.
- الأمر التالت بياخد نسخة من `~\.claude\settings.json` و`CLAUDE.md` للأرشيف، وبعدها بيركّب: 3 هوكات، والسكيلز، والبلاجنز (`hyperframes` و`remotion`)، وسطر `@` بيسحب `TALK-TO-ME.md` في كل جلسة، ومتغير `CLAUDE_WORKFLOW`.
- بعدها افتح جلسة `Claude Code` جديدة وقوله: «اقرا `START-HERE.md`». هيقرا `NEW-PC-SETUP.md` ويعرض عليك الناقص على جهازك في رسالة واحدة.

## النظام بيقرا إيه وإمتى (عشان التوكنز)

| إمتى | اللي بيتقري |
|---|---|
| كل جلسة | `TALK-TO-ME.md` بس (قواعد الكلام)، وسطرين وصف لكل سكيل |
| أول شغل فيديو | `START-HERE.md` و`Kit_01_General_Video_Rules\00_quick_rules.md` |
| مرحلة معيّنة (حركة، كتابة عربي، AE، صوت) | القسم المطلوب بس من ملفات `01`–`05` |
| نوع ريل أو ستايل معيّن | السكيل بتاعته بس (`reel-talking-head`، `reel-music-montage`، `style-…`) |

- كل ستايل جديد بيتعمل سكيل لوحدها، فمفيش ستايل بيتقري غير لما يتطلب.
- لو الطلب ينفع لأكتر من ستايل، `Claude` بيسأل سؤال واحد قبل ما يفتح أي سكيل.

## النظام بيطوّر نفسه إزاي

- **هوك آخر الجلسة:** لما تقفل الجلسة («خلصنا»، «شكرا»…) `Claude` بيراجع اللي اتعلمه: تصحيحاتك، والأخطاء وحلها، والسكيلز، وملف العميل. بيعرض ملخص 5 سطور وبيستنى موافقتك.
- **هوك أول الجلسة:** لو الجلسة اللي فاتت اتقفلت من غير مراجعة، بيقولك في سطر.
- **هوك حماية الكريدت:** بيسألك قبل أي أداة بتصرف كريدت (ElevenLabs، Magnific، Higgsfield).
- **قواعدك إنت** بتتكتب في `MY-RULES.md`، وعملاءك في `Kit_04_Clients\`، ومسارات جهازك في `THIS-PC.md`. التلاتة دول `git` مش بيتتبّعهم.
- **تحديثات عمر** بتيجي بـ `git pull` من جوه الفولدر، ومش بتلمس ملفاتك التلاتة. لو التحديث فيه سكيلز جديدة شغّل `Kit_01_General_Video_Rules\tools\sync_skills.ps1`.


## ملاحظات

- المفاتيح (`ElevenLabs`، `Gemini`…) مش في الريبو. مكانها `keys\` جنب الفولدر، والشكل في سكيل `free-llm-delegate`.
- مكتبة الساوند هنا فيها الـ 12 صوت الأساسيين (متولّدين بـ ElevenLabs، والبرومبتات في `generations.json`) وأصوات CC0 من Freesound بس. الباكات المرخّصة (`Flex UI SFX` وأصوات Epidemic Sound) مش في الريبو: حط نسختك منها في `SFX_Library\more-sfx-added-by-omar\` بالأسامي المكتوبة في `README.md` اللي هناك.
- الأكواد `CLA`، `CLB`… و`AG1`، `AG2` في القواعد هي عملاء ووكالات حقيقيين أساميهم متشالة. الكود جنب القاعدة بيقول القاعدة دي جت من أنهي شغل بس.
