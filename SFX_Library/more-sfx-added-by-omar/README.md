# مكتبة الساوند الإضافية

> الفولدر ده في الريبو فيه أصوات CC0 بس (`cash\`). الباكات اللي تحت مرخّصة ومش بتتنشر: لو عندك رخصتها، حطها هنا بنفس أسامي الفولدرات عشان القواعد والسكريبتات تلاقيها.

| الفولدر | المصدر | فيه إيه |
|---|---|---|
| `Flex UI SFX\` | باك `Flex UI SFX` (298 ملف `wav`) | كليكات وأصوات واجهات |
| `risers and hits\` | Epidemic Sound (أسامي الملفات بتبدأ بـ `ES_`) | رايزر، بيلد، ضربة درام واطية |
| `textures\` | Epidemic Sound | كيبورد، كليكات، خامات |
| `whoosh\` | Epidemic Sound | ووشات |

- لو مفيش عندك الباكات دي، النظام شغال بالـ 12 صوت الأساسيين في `SFX_Library\`، واللي ناقص بيتولّد أو بيتجاب CC0 من Freesound (`Kit_01_General_Video_Rules\05_audio_sfx.md`).
